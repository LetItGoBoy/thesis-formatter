# 关卡与章节生产模板

## 每章固定结构

每章建议拆成 4 到 5 个小节。每个小节都要完成一个小闭环：剧情推进、知识引入、任务操作、关卡测试、状态变化。

标准结构：

1. 剧情开场
2. 概念出现
3. 原理展开
4. 任务执行
5. 小 BOSS 或悬念

## 小节模板

每个小节对应一个网站里的关卡。

```text
关卡编号：
关卡名称：
剧情目标：
知识目标：
学生要完成的事：
测试题数量：
通关条件：
解锁内容：
```

示例：

```text
关卡编号：1-2
关卡名称：顺序表：连续空间与快速访问
剧情目标：林澈需要在连续排列的任务节点中快速定位第 47 个异常任务。
知识目标：理解顺序表的随机访问优势。
学生要完成的事：判断什么场景适合顺序表。
测试题数量：4
通关条件：答对 3 题
解锁内容：节点管理 +1，秩序协议 4%
```

## 状态卡字段

学生状态卡用于把知识积累可视化。

基础字段：

- 学生昵称
- 当前等级
- 当前章节
- 已通关关卡数
- 秩序协议完成度
- Null 线索数量
- 已解锁技能
- 当前薄弱知识点
- 下一关

等级建议：

| 等级 | 名称 | 对应阶段 |
| --- | --- | --- |
| Lv.1 | 断点观察者 | 序章 |
| Lv.2 | 节点修复员 | 线性表 |
| Lv.3 | 回溯追踪者 | 栈 |
| Lv.4 | 调度执行官 | 队列 |
| Lv.5 | 模式识别员 | 串 |
| Lv.6 | 层级建模师 | 树 |
| Lv.7 | 图域导航者 | 图 |

## 技能标签

技能标签必须对应课程能力，不做空泛徽章。

- 节点管理：理解顺序、连接、插入、删除
- 回溯追踪：理解后进先出和递归回退
- 调度秩序：理解先进先出和优先级
- 模式识别：理解字符串匹配
- 层级建模：理解树和遍历
- 关系网络：理解图和路径
- 快速定位：理解查找策略
- 效率优化：理解排序策略和复杂度

## 每章点睛规则

点睛句必须满足：

- 不超过 30 字
- 直接说明该结构解决的问题
- 不写成定义
- 能让学生记住“为什么学”

例子：

- 线性表：让一组数据拥有明确的前后关系。
- 栈：让系统拥有返回现场的能力。
- 队列：在资源有限时建立等待规则。
- 图：处理现实中复杂的关系网络。
