# 数据结构课程 IP：霓虹栈城

本目录用于沉淀“数据结构”课程的有声小说、闯关学习和课程产品设定。

当前故事名暂定：

**《霓虹栈城：断点回声》**

## 文件说明

- `story-bible.md`  
  故事圣经。固定世界观、主角团、主线冲突、Null、秩序协议和创作原则。

- `chapter-map.md`  
  章节映射表。把数据结构知识点映射到剧情事件、关卡、技能解锁和悬念。

- `level-template.md`  
  关卡生产模板。后续每章、每节、每个小测试都按这个结构扩展。

- `quiz-design.md`  
  题库设计规则。定义每关题型、反馈方式、后台数据字段和第一章题目样例。

- `prologue-script.md`  
  序章《雨夜断点》的完整混合稿，包含小说、对白、音效提示、关卡和状态卡。

- `prologue-feishu-novel.md`
  飞书听书版小说正文。去掉剧本标记和音效提示，适合直接粘贴到飞书云文档，用手机端“语音朗读”功能播放。

- `prologue-teaching-notes.md`
  序章教学设计稿。包含知识落点、关卡设计、状态卡、题目样例和飞书/网站分工。

## 推荐工作流

1. 先确认 `story-bible.md` 是否符合课程气质。
2. 再确认 `chapter-map.md` 的知识顺序和课程内容是否匹配。
3. 将 `prologue-feishu-novel.md` 放入飞书云文档，测试手机端朗读效果。
4. 根据 `prologue-teaching-notes.md` 制作序章关卡和状态卡。
5. 按 `level-template.md` 制作第一章“线性表街区”。
6. 按 `quiz-design.md` 生成每小节测试题。
7. 网站端再做章节地图、状态卡、关卡页和后台数据。

## 产品原则

- 飞书放有声小说、文字稿、资料、推荐视频。
- 网站放关卡、答题、状态卡、技能解锁、后台数据。
- 小说负责沉浸，网站负责闭环。
