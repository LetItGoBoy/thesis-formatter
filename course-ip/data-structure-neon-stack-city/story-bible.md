# 《霓虹栈城：断点回声》故事圣经

## 项目定位

《霓虹栈城：断点回声》是“数据结构”课程的赛博朋克有声小说与闯关学习 IP。

它不是把知识点硬塞进小说，而是让学生跟随主角调查城市崩坏事件，在剧情中自然遇到线性表、栈、队列、串、树、图、查找、排序等结构。每章对应一个课程知识模块，每个小节对应一个关卡，学生通过测试后解锁能力，最终完成对幕后破坏者 Null 的反击。

核心目标：

- 用故事解释“为什么要学数据结构”
- 用事件引出概念，而不是先讲定义
- 用关卡确认理解，而不是只听剧情
- 用状态卡展示知识与技能积累
- 用最终冲突串起整门课的意义

## 世界观

栈城是一座高度数字化的学院城市。

城市中的身份、交通、课程、任务、权限、积分、实验预约、应急调度，都依赖底层结构网络维持秩序。普通人只看到界面和结果，看不到背后的结构。可一旦结构被破坏，城市会立刻失序。

当结构崩坏时，会出现：

- 任务无法排队
- 路径无法抵达
- 身份无法匹配
- 记录无法回溯
- 权限无法继承
- 信息无法检索
- 积分和优先级全部错乱

数据结构在这个世界里的意义：

> 没有结构，数据只是一堆噪声；有了结构，世界才有被理解和修复的可能。

## 主线冲突

栈城出现一系列“断点事件”。

最初看起来只是系统故障，但主角团逐渐发现，这些故障不是随机发生的，而是有人在有计划地破坏城市底层结构。

幕后破坏者代号：**Null**。

Null 不是普通黑客，而是一个极端秩序否定者。他认为所有结构最终都会变成控制人的牢笼，所以他要让栈城回到“无结构状态”。

Null 的破坏方式不是炸毁系统，而是精准攻击结构：

- 删除关键节点
- 篡改指针
- 打乱队列
- 伪造路径
- 污染索引
- 制造循环依赖
- 切断树形权限
- 干扰排序与检索

主角团要做的不是“开发一个系统”，而是在每章任务中逐步重建一套城市防线：**秩序协议**。

## 核心概念：秩序协议

秩序协议不是课程项目名，而是剧情中的核心武器。

每学完一种数据结构，秩序协议就获得一个能力模块。到最终章，主角团用它定位 Null、识别破坏路径，并阻止 Null 发动最后一次城市级崩坏。

秩序协议能力积累：

- 线性表：节点管理
- 栈：回溯追踪
- 队列：调度秩序
- 串：模式识别
- 树：层级建模
- 图：关系网络
- 查找：快速定位
- 排序：效率优化

## 主要角色

### 林澈

主角。栈城学院新生。

他不是天才型角色，最初也不理解数据结构有什么意义。序章中，他意外看见系统屏幕上的“断点回声”，被卷入栈城崩坏事件。

成长线：

- 初期：只想通过课程，不想惹麻烦
- 中期：发现结构能解释混乱
- 后期：理解数据结构是复杂世界的秩序骨架

角色功能：

- 代表学生视角
- 负责提出“为什么要学这个”
- 在任务中逐步获得结构化思维

### 祁蓝

高年级学生，冷静、锋利、观察力强。

她擅长日志分析、代码追踪和异常推理。她不是单纯讲知识的角色，而是在事件中把“概念背后的原理”说清楚。

角色功能：

- 推动推理
- 引出概念与原理
- 负责知识之间的关联

### 阿铎

行动派，嘴贫，有游戏玩家气质。

他负责进入现场执行任务，也经常犯学生会犯的错误，例如把“能跑”当成“理解了”，把“背会定义”当成“会用了”。

角色功能：

- 制造轻松感和包袱
- 代表常见误区
- 让抽象知识落到行动场景

### MIRA

城市旧版引导 AI。

表面上是课程辅助系统，实际保存着上一代秩序协议的残片。它的记忆被删过，很多时候只会给出片段式提示。

角色功能：

- 旁白与引导
- 每章结尾点睛
- 承担伏笔与反转

### 沈砚

栈城学院导师。

他知道 Null 的过去，也知道上一代秩序协议为何失败，但他不会一开始说出全部真相。

角色功能：

- 发布任务
- 控制节奏
- 在关键章揭示历史

### Null

最终 BOSS。

曾是栈城最优秀的系统设计者之一，后来认为结构会制造束缚，秩序会吞掉个体差异。他不想统治栈城，而是要让栈城失去组织方式。

角色功能：

- 制造主线冲突
- 代表“无结构状态”
- 用破坏行为反向凸显数据结构的意义

- 每章结尾必须有悬念或线索推进
- 每章必须有一句点睛，说明该结构解决了什么问题
- 可以有包袱，但不要破坏悬疑和沉浸感

## 知识关系原则

数据结构的知识不是孤立的：

- 线性表是基础组织方式
- 栈和队列是受限线性表
- 串是特殊线性结构
- 树表达层级关系
- 图表达复杂关系网络
- 查找关注如何快速定位
- 排序关注如何组织顺序以提升效率

创作时必须体现这些关系。学生听完整部小说后，应该能感到：后面的知识不是突然冒出来的，而是在不断扩展“如何组织复杂数据”这个核心问题。

## 第一季最终目标

主角团最终不是完成一个普通软件，而是完成“秩序协议”的最后拼合。

最终章中，Null 试图让整个栈城进入无结构状态。主角团必须综合使用前面章节获得的能力：

- 用线性表恢复关键节点顺序
- 用栈回溯入侵轨迹
- 用队列重建调度
- 用串匹配异常特征
- 用树恢复权限层级
- 用图找到真实路径
- 用查找定位 Null 的核心入口
- 用排序恢复任务优先级

最终点睛：

> 数据结构不是为了记住概念，而是为了在复杂系统中建立秩序。
